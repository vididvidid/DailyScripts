# DownloadChatAndMinifyJSONandText

A Tampermonkey script to download chat conversations and minify JSON/text content for efficient storage and processing.

## Features

- **Chat Download**: Extracts and downloads chat conversations from supported platforms.
- **JSON Minification**: Compresses JSON data to reduce file size.
- **Text Minification**: Removes unnecessary whitespace and comments from text content.
- **Cross-Platform**: Works with any website where Tampermonkey is supported.

## Installation

1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension.
2. Create a new script in Tampermonkey:
   - Click the Tampermonkey icon → **Create a new script...**
3. Replace the default content with the script from `DownloadChatandMinifyJSONandText.js`.
4. Save the script (`Ctrl + S` or `Cmd + S`).
5. The script is now active and ready to use.

## Usage

1. Navigate to the chat interface you want to process.
2. Trigger the script (e.g., via a keyboard shortcut or Tampermonkey menu).
3. The script will:
   - Extract the chat content.
   - Minify JSON/text (if applicable).
   - Generate a downloadable file.
