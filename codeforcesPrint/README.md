# Codeforces ICPC Print (`codeforcesPrint.js`)

Prints **one** Codeforces problem on A4 portrait paper, laid out the way ICPC
contests hand problems out. A print icon appears next to the problem title; click
it to print just that problem, without the site's menus, sidebar and comments.

Works on problem pages under `problemset`, `contest`, `gym` and `group`, on
`codeforces.com` and its mirrors (`*.codeforces.com`). It needs no GM functions
(`@grant none`).

## Install

The file carries its own `==UserScript==` header, so it installs as it is: in
[Moss](https://github.com/vididvidid/Moss) use **Import…** with this file's GitHub link
(or **+ Script** and paste it); in Tampermonkey paste it into a new script. See the
[installation guide](../README.md#installation) for live reload and updates.
