tinkatuff demo

A deliberately badly built "patient portal" on your own machine. Every flaw below is planted on purpose so tinkatuff has something to find. Nothing here talks to a real service; the secrets are generated in your browser each time the page loads.

What is planted

  • Served over plain HTTP — broken today
  • A private key printed with console.warn — broken today
  • A password saved in localStorage — broken today
  • The password RSA-encrypted with JSEncrypt and POSTed — recorded now, unlocked later
  • ECDH P-256 and RSA-OAEP keys made with WebCrypto; an ECDH private key stored in IndexedDB — recorded now, unlocked later
  • A WebAssembly module with mbedTLS RSA / ECDH symbols; a WebRTC connection — recorded now, unlocked later
  • RS256 / ES256 JWTs in a cookie, in storage and in an Authorization header; an ES256 DPoP proof — could be faked later
  • JWKS, security.txt PGP key and did.json with RSA / Ed25519 / secp256k1 keys — could be faked later
  • Login cookie readable by JavaScript and valid for two years; a refresh token in localStorage — other weak spots
  • A CDN script without SRI; SHA-1 and AES-128 in WebCrypto; a 'DES-EDE3-CBC' string in code — other weak spots
  • A worker whose source map lists tweetnacl, node-forge and @noble/post-quantum — found by the deep scan

Click the tinkatuff button, then Deep scan for the worker, source map, JWKS, security.txt, did.json and IndexedDB checks. DNS, email and certificate checks need a real domain, so on localhost they report "nothing found".
