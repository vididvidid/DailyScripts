Putting it on a phone

  1. Build it here, press Copy. (Easiest on the phone itself — open this page there.)
  2. Bookmark any page, then edit that bookmark: replace its URL with what you copied, and name it AiUtil.
  3. Chrome / Android: open an AI chat, type AiUtil in the address bar and pick the bookmark from the suggestions. Safari / iOS: save it under Favourites and tap it from the bookmarks menu.

What you give up versus Tampermonkey

  • It runs once per page load — reopen it after a reload.
  • Prompts are stored in that site's localStorage instead of Tampermonkey, so they are per-site and are wiped when you clear site data.
  • Gist sync usually will not work: without GM_xmlhttpRequest the call falls back to fetch(), which these sites' CSP blocks. Sync from the desktop, use prompts here.
  • If your browser refuses to save a bookmark this long, install Violentmonkey on Firefox for Android and use the normal userscript instead — that path has none of these limits.
